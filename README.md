# MrFab — Scrollytelling Website

A responsive, single-page agency website designed for GitHub Pages.

## Publish on GitHub Pages
1. Extract this ZIP.
2. Upload `index.html`, `style.css`, `script.js` and `README.md` to the root of your GitHub repository.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select your branch (usually `main`) and folder `/ (root)`, then Save.

## Before publishing
- In `index.html`, replace `YOUR-EMAIL@example.com` with your real business email.
- Update the service descriptions and contact copy if needed.
- Google Fonts and GSAP are loaded from CDNs, so those effects require an internet connection.
- This is a static front-end site. A working enquiry form, CMS, or admin dashboard would need a form service or backend.

## Files
- `index.html` — page structure and content
- `style.css` — layout, responsive styling and visual effects
- `script.js` — GSAP scroll animations and mobile navigation

- `hero-video.mp4` — supplied full-screen looping hero background video.
